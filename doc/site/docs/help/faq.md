# FAQ

## Where is my data stored?

OpenTodoList stores your data in libraries. A library can stay local to one
device, or it can be synchronized with a supported service.

## Do I need an account?

No. You only need an account if you want to use a sync service that requires
one, such as Nextcloud, ownCloud, WebDAV, or Dropbox.

## Can I keep everything local?

Yes. Local libraries stay on the device where you create them.

## Where can I report bugs or request features?

Use the [GitLab issue tracker](https://gitlab.com/rpdev/opentodolist/-/issues).
