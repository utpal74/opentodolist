# Troubleshooting

This page will collect common issues and fixes for OpenTodoList.

For now, if something does not work as expected, please check the
[GitLab issue tracker](https://gitlab.com/rpdev/opentodolist/-/issues) or open
a new issue with the platform, OpenTodoList version, and a short description of
what happened.

If your issue is related to synchronization, the [sync section](../sync/index.md)
is the best place to start.
