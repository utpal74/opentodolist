## Google Play

Install OpenTodoList from
[Google Play](https://play.google.com/store/apps/details?id=net.rpdev.opentodolist).
This is the easiest option for most Android users.

## IzzyOnDroid

If you prefer an F-Droid style workflow, install OpenTodoList from
[IzzyOnDroid](https://apt.izzysoft.de/fdroid/index/apk/net.rpdev.opentodolist).
To use it, add the
[IzzyOnDroid F-Droid repository](https://apt.izzysoft.de/fdroid/) to your
Android device first.

## APK Downloads

Pre-built APK files are also published on
[GitHub Releases](https://github.com/mhoeher/opentodolist/releases). This can
be useful if you cannot use Google Play or IzzyOnDroid.

For most users, installing through Google Play or IzzyOnDroid is still the
better option because updates are handled by the store app.

## First Run

After installation, open OpenTodoList and create a library. You can keep the
library local on your phone or tablet, or set up sync later.

Continue with [Getting Started](../../manual/getting-started.md).
