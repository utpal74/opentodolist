# Installation

This section collects platform-specific installation notes for OpenTodoList.
Most users should install a ready-made package from an app store or release
page.

- [Android](./android.md)
- [iOS](./ios.md)
- [Linux](./linux.md)
- [macOS](./macos.md)
- [Windows](./windows.md)

If you need the app on another system, you can try to
[build it yourself](../../project/build-from-source.md).

Once OpenTodoList is installed, continue with
[Getting Started](../../manual/getting-started.md).
