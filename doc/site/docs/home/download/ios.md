Install OpenTodoList from the
[App Store](https://apps.apple.com/us/app/opentodolist/id1490013766).

## First Run

After installation, open OpenTodoList and create a library. You can keep the
library local on this device or configure synchronization if you want to use the
same library on multiple devices.

Continue with [Getting Started](../../manual/getting-started.md).
