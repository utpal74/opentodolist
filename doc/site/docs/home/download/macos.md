# macOS

OpenTodoList packages for macOS are published on GitHub Releases.

- Download the macOS package from
  [GitHub Releases](https://github.com/mhoeher/opentodolist/releases).
- Open the downloaded package and copy the app into your Applications folder.
- Start OpenTodoList from your Applications folder or launcher.

## First Run

After installation, open OpenTodoList and create a library. You can keep it
local on your Mac or set up synchronization to use the same library elsewhere.

Continue with [Getting Started](../../manual/getting-started.md).
