# Windows

OpenTodoList packages for Windows are published on GitHub Releases.

- Download the Windows installer or archive from
  [GitHub Releases](https://github.com/mhoeher/opentodolist/releases).

You have two options:

- Installer: Prefer this option if possible.
- Zip archive: If you cannot run installers on your system,
  you can use this option. After download, unzip the archive
  to a suitable location and run the contained `OpenTodoList.exe`.

## First Run

After installation, open OpenTodoList and create a library. You can keep it
local on your PC or set up synchronization to use the same library elsewhere.

Continue with [Getting Started](../../manual/getting-started.md).
