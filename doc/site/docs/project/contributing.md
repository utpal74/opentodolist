# Contributing

OpenTodoList is an open source project. You can help by reporting issues,
requesting improvements, translating the app, improving documentation, or
contributing code.

## Report Issues

If you found a bug or have an idea for a new feature, open an issue in the
[GitLab issue tracker](https://gitlab.com/rpdev/opentodolist/-/issues).

## Translate

Translations are managed through
[POEditor](https://poeditor.com/join/project/ztvOymGNxn).

## Contribute Code

The source code is hosted on
[GitLab](https://gitlab.com/rpdev/opentodolist). Fork the project, make your
changes, and open a merge request when you are ready.
