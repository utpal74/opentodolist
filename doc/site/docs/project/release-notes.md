# Release Notes

Release notes are currently published with OpenTodoList releases:

- [GitHub Releases](https://github.com/mhoeher/opentodolist/releases)
- [GitLab project](https://gitlab.com/rpdev/opentodolist)

Future release notes can be collected here as the website and documentation are
consolidated.

## Release Cadence

OpenTodoList moved away from monthly feature releases in 2021. The project now
generally aims for less frequent feature releases so larger changes have more
time for implementation and testing.

Bug fix releases may happen between regular feature releases, especially for
important problems or issues that affect a specific platform or package format.
Depending on the issue, such releases may be scoped to the affected platform.

## Beta Testing

Some distribution channels make it possible to test builds before the next
regular release. Availability depends on the platform and packaging channel.

Beta builds are useful if you want to try recent changes early or help verify a
fix. They may also be less polished than regular releases, so avoid using them as
your only copy of important data unless you have backups.
