# Dropbox

OpenTodoList can synchronize libraries through Dropbox if that is where you want
to keep your app data.

Use this backend when you already rely on Dropbox and want OpenTodoList
libraries to be available on multiple devices without setting up your own
Nextcloud, ownCloud, or WebDAV server.

## Things To Keep In Mind

Dropbox is a third-party storage service. Data synchronized through this backend
is stored in the Dropbox account you connect. Review Dropbox's own privacy and
security settings if you use this option for sensitive information.

If you prefer to keep tighter control over the server, consider Nextcloud,
ownCloud, WebDAV on infrastructure you trust, or a local library synchronized by
your own tooling.
