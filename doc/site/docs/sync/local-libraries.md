# Local Libraries

A local library is stored only on the device where you create it. OpenTodoList
does not copy it to a server by itself.

This is the simplest and most private setup: your data stays in the library
folder on that device unless you back it up or synchronize it with another tool.

## Using External Sync Tools

OpenTodoList libraries are normal folders and files. That means you can sync a
local library with tools outside OpenTodoList, for example a file synchronization
tool provided by your operating system, storage provider, or organization.

When using an external sync tool, make sure the same files are not edited on
multiple devices at the exact same time. Let the sync tool finish uploading and
downloading changes before opening the library elsewhere.

## Backups

Local libraries are not automatically backed up by OpenTodoList. If the device
is lost or damaged, a local-only library can be lost as well.

For a manual backup workflow, see [Backup](../manual/backup.md).
