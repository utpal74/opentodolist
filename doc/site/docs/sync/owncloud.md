# ownCloud

OpenTodoList can synchronize libraries with ownCloud in much the same way as
with Nextcloud. The app stores library files in your account and updates them
when you sync from another device.

## When To Use ownCloud

Use this backend when you already have an ownCloud server or account and want
OpenTodoList data to follow you across devices without using a fixed
OpenTodoList-hosted service.

## Security Notes

Use HTTPS for the ownCloud server whenever possible. With plain HTTP, data and
login information can be exposed while in transit.

If you maintain the server yourself, keep the ownCloud installation and its web
server configuration up to date.
